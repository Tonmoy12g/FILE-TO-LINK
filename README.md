# File-to-Link Bot (Telegram)

ইউজার যেকোনো ফাইল পাঠালে বট সেটি আপলোড করে একটি ডাউনলোড লিংক ফেরত দেয়।

## কীভাবে কাজ করে

ইউজার ফাইল পাঠায় → বট ফাইলটি ডিস্কে টেম্প ফাইলে ডাউনলোড করে (মেমোরিতে লোড করে না) → `uploader.py`-এর মাধ্যমে হোস্টিংয়ে আপলোড করে → লিংক যাচাই করে → ফাইলের নাম, সাইজ ও লিংকসহ রিপ্লাই দেয়। টেম্প ফাইল সবসময় মুছে ফেলা হয়।

## ফিচার

- 📤 সব ধরনের ফাইল: ডকুমেন্ট, ছবি, ভিডিও, অডিও, ভয়েস, GIF অ্যানিমেশন, ভিডিও নোট, স্টিকার
- 🔗 শেষ লিংক, 📊 নিজের পরিসংখ্যান, 📚 সাহায্য, 💬 সাপোর্ট — বাটনভিত্তিক মেনু
- ♻️ একই ফাইল আবার পাঠালে আগের লিংকই ফেরত (ডুপ্লিকেট আপলোড হয় না)
- 🛠️ অ্যাডমিন প্যানেল (`/admin`): মোট ইউজার/ফাইল/স্টোরেজ, ব্রডকাস্ট (`/broadcast`), মেইনটেন্যান্স ON/OFF, ওয়েলকাম মেসেজ (`/setwelcome`), এরর লগ
- 🔁 আপলোডে ৩ বার রিট্রাই + ব্যাকঅফ; লিংক পাঠানোর আগে যাচাই (verify)
- 🗄️ পরিসংখ্যান SQLite-এ সংরক্ষিত

## ফাইলসমূহ

| ফাইল | কাজ |
|---|---|
| `bot.py` | মূল বট (হ্যান্ডলার, মেনু, অ্যাডমিন, Flask keep-alive) |
| `uploader.py` | **একমাত্র স্টোরেজ মডিউল** — প্রোভাইডার বদলাতে শুধু এখানেই বদলাতে হয় |
| `db.py` | SQLite (users, uploads, settings, errors) |
| `requirements.txt` | python-telegram-bot, Flask, httpx |
| `DEPLOY.md` | ধাপে ধাপে ডিপ্লয় গাইড (বাংলা) |
| `.env.example` | সব এনভায়রনমেন্ট ভেরিয়েবলের তালিকা |

## আপলোড প্রোভাইডার (গুরুত্বপূর্ণ)

`UPLOAD_PROVIDER` এনভ দিয়ে বদলানো যায়: `gofile` (ডিফল্ট) | `catbox` | `litterbox`

- **GoFile — ✅ লাইভ টেস্টে পাস (ডিফল্ট):** অ্যানোনিমাস আপলোড কাজ করে; সার্ভারের দেওয়া MD5 ও লোকাল ফাইলের MD5 মিলিয়ে যাচাই করা হয়েছে। লিংকগুলো **ডাউনলোড পেজের লিংক** (gofile.io/d/...), সরাসরি ফাইলের লিংক নয়। গেস্ট আপলোড দীর্ঘদিন ডাউনলোড না হলে মুছে যেতে পারে।
- **Catbox / Litterbox — ⚠️ এই বিল্ড পরিবেশ থেকে লাইভ যাচাই করা যায়নি:** catbox.moe ডোমেইনটি বিল্ড স্যান্ডবক্স থেকে একদমই unreachable ছিল (HTTP 000)। কোড স্ট্যান্ডার্ড ডকুমেন্টেড API অনুযায়ী লেখা এবং Render থেকে কাজ করতে পারে, কিন্তু গ্যারান্টি দেওয়া যাচ্ছে না। ব্যবহার করতে চাইলে `UPLOAD_PROVIDER=catbox` দিয়ে ছোট ফাইল পাঠিয়ে নিজে টেস্ট করে নিন। (Catbox চললে সত্যিকারের direct link পাওয়া যাবে।)

## লোকালে চালানো

```bash
pip install -r requirements.txt
TELEGRAM_BOT_TOKEN=xxx ADMIN_CHAT_ID=123456789 python bot.py
```

## সীমাবদ্ধতা (সংক্ষেপে)

- Telegram cloud Bot API দিয়ে **২০ MB-এর বড় ফাইল ডাউনলোড করা যায় না** — তাই এই সেটআপে সীমা ২০ MB। ২ GB পর্যন্ত পেতে VPS-এ নিজস্ব local Bot API server লাগবে।
- Render ফ্রি প্ল্যানে সার্ভিস ঘুমিয়ে যায় (প্রথম রিপ্লাই ৩০–৬০ সেকেন্ড লাগতে পারে) এবং SQLite ফাইল রিডিপ্লয়ে মুছে যেতে পারে। বিস্তারিত: `DEPLOY.md`
